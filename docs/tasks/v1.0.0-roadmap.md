# v1.0.0 Roadmap

## Blockers

Must be resolved before tagging v1.0.0.

### P6-001: Wire config into planners
**Status:** In progress
**Effort:** 6-8 hours

Nine configuration options (`auto_push`, `pr_draft`, `merge_strategy`,
`branch_prefix`, `delete_on_merge`, etc.) are defined and loaded but never
read by the planners or executor. Users can set them in `.jetsam/config.yaml`
with no effect.

### P6-002: Standardize MCP error responses
**Status:** In progress
**Effort:** 3-4 hours

MCP tools return errors inconsistently — some as `{"error": ...}`, some as
`[{"error": ...}]`, with different key sets. Agents need a uniform way to
detect and handle errors. All errors should use the `JetsamError` format.

### GitLab stance
**Status:** Needs decision
**Effort:** Documentation only (or 8-12 hours for full implementation)

Four new verbs (`pr_comment`, `pr_review`, `pr_comments`, `issue_close`) raise
`NotImplementedError` on GitLab. Options:

1. **Document as GitHub-first** — add a "Platform Support" section noting
   GitHub is fully supported, GitLab has partial support. Ship v1.0.0.
2. **Implement glab equivalents** — full parity. Delays v1.0.0.

Recommendation: option 1. GitLab parity can follow in v1.1.0.
